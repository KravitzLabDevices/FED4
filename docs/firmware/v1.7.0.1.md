Rebuild the **library** after confirming `FED4_ENABLE_TOUCH_LOG` is `1` in [`src/FED4.h`](../../src/FED4.h). An `.ino` `#define` does not reach library sources.

## What changed in this firmware (library)

Relative to un-instrumented 1.7.0 production touch. Sources: [`FED4_Touch.cpp`](../../src/FED4_Touch.cpp), [`FED4_TouchHelpers.h`](../../src/FED4_TouchHelpers.h), [`FED4_Sleep.cpp`](../../src/FED4_Sleep.cpp).

1. **Shorter measurement** — `TOUCH_MEASURE_CYCLES` 2000 → **200** (~1 ms on Left, IDF-recommended). The old ~9.7 ms measurement left no headroom; a loaded pad ran out of range and **stopped the FSM**.
2. **Measurement-timeout recovery** — `touch_pad_timeout_set` / `touch_pad_timeout_resume` (`fed4TouchServiceTimeout`). Out-of-range readings resume instead of freezing Smooth/Bench on all pads.
3. **ISR pad latch** — latches `status_mask` edge, not `touch_pad_get_current_meas_channel()` (that register is whichever channel the FSM is scanning *now*, which skewed pad ID).
4. **Confirm vote** — post-sleep ID needs agreeing samples (`ConfirmAgreed`); no unvoted single-sample winner.
5. **Characterization bounds** — rescue / rechar rejected if Idle would move more than `TOUCH_CAL_MAX_IDLE_DEVIATION_FRAC` from first boot char (`CalReject`). Stops the field failure where a 13.8× Idle jump made a pad permanently unresponsive.
6. **Stale-benchmark watchdog** — if `smooth − bench >= wakeAbs` for `FED4_TOUCH_BENCH_STUCK_MS` (5 min), force `touch_pad_reset_benchmark` (`BenchReset`).
7. **Bounded pre-sleep release wait** — cap `FED4_TOUCH_RELEASE_WAIT_MS` (5 s) instead of spinning forever (`Stuck` / `ReleaseWait`).
8. **Touch diagnostic CSV** — `_T.CSV` with Smooth / Bench / Idle / `wakeAbs`, `ScanPeriodUs`, `MeasUs{L,C,R}`, `TimeoutCount`, `IsrMask`, `ConfirmAgreed`, etc.
9. **Display trackability** — Task shows `AwakeDrift` / `SleepDrift`; firmware `v1.7.0.1` on Task-right and footer.

NVS poke-delta calibration remains **WIP** (`begin()` does not auto-load it).
